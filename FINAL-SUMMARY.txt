$ npm install

→ http://localhost:3000/admin
   Anmelden mit: admin / admin123

TERMINAL 2 - Website starten:
────────────────────────────

$ python3 -m http.server 8080

→ http://localhost:8080

📡 API ENDPOINTS

Public Endpoints (keine Auth nötig):
  GET  /api/news                 Alle News
  GET  /api/news/:id             Einzelne News
  GET  /api/events               Alle Events
  GET  /api/services             Alle Services

Admin Endpoints (Auth erforderlich):
  POST   /api/admin/news         Neue News
  PUT    /api/admin/news/:id     News ändern
  DELETE /api/admin/news/:id     News löschen
  
  (Gleich für Events & Services)

⚡ WIE ALLES FUNKTIONIERT

1. Du startest Backend
   → SQLite Datenbank wird erstellt
   → Admin-Panel wird erreichbar
   → API läuft auf Port 3000

2. Du meldest dich an
   → Admin-Panel öffnet sich
   → Du siehst Dashboard

3. Du fügt News/Events ein
   → Werden in Datenbank gespeichert
   → API gibt die Daten zurück

4. Website lädt Daten
   → neuigkeiten.html ruft /api/news auf
   → events.html ruft /api/events auf
   → Daten werden automatisch angezeigt

5. Besucher sehen Updates
   → Sofort, keine Verzögerung!
   → Keine manuellen Änderungen nötig

❌ TROUBLESHOOTING

"Cannot find module 'express'"
  → cd kunsttherapie-cms && npm install

"Port 3000 already in use"
  → Andere App nutzt Port
  → Ändere PORT in .env
  → Oder: lsof -ti:3000 | xargs kill -9

"Login fehlgeschlagen"
  → admin / admin123
  → Achte auf Groß-/Kleinschreibung
  → Starte Server neu

"News/Events zeigen sich nicht"
  → Backend läuft nicht!
  → Öffne http://localhost:3000
  → Sollte nicht "Verbindung verweigert" sagen

"JavaScript Error in Browser"
  → F12 drücken
  → Schau Console
  → Backend läuft? Port 3000?
