# Bild-Assets

Die aktuelle Preview nutzt bewusst CSS-basierte Editorial-/Atelier-Flächen, damit die Website ohne fehlende Foto-Dateien sofort funktioniert.

Wenn echte Praxis-, Atelier- oder Werkfotos vorliegen, bitte hier ablegen und dann in den HTML-Dateien referenzieren, zum Beispiel:

```text
kunsttherapie-site/assets/img/atelier.jpg
kunsttherapie-site/assets/img/gruppe.jpg
kunsttherapie-site/assets/img/logo.png
```

Empfehlung:

- Logo unter 200 KB
- Hero-/Galeriebilder als WebP oder optimiertes JPG
- sinnvolle `alt`-Texte in den HTML-Dateien ergänzen
