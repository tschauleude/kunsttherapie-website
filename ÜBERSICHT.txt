KUNSTTHERAPIE PADERBORN - AKTUELLE PROJEKTUEBERSICHT

Status: praesentationsfaehige Website + CMS

ORDNER

1. kunsttherapie-site/
   - moderne Website im hellen Watercolor-/Atelier-Design
   - Seiten: Start, Angebote, Ueber mich, Preise, Neuigkeiten, Termine, Kontakt, Impressum, Datenschutz
   - interaktives Mini-Atelier
   - API-Fallbacks fuer sichere Demo
   - Favicon, Manifest, Robots und Sitemap

2. kunsttherapie-cms/
   - Node.js/Express Backend
   - SQLite Datenbank
   - Admin-Panel
   - News, Termine und Angebote verwalten
   - Login, Rate-Limit, Passwortwechsel
   - Public API fuer Website

SCHNELLSTART

Backend:
  cd kunsttherapie-cms
  npm install
  cp .env.example .env
  npm run dev

Website:
  cd kunsttherapie-site
  python3 -m http.server 8080

URLs:
  Website: http://localhost:8080
  Admin:   http://localhost:3000/admin
  Health:  http://localhost:3000/api/health

DESIGN

- warmes Papier/Creme als Grundflaeche
- Gold, Aquarell-Blau, Naturgruen und Rose als Akzente
- weiche Karten, organische Farbformen, ruhige Animationen
- hochwertig, modern, kreativ und passend fuer Kunsttherapie

WICHTIG

- Inhalte im CMS pflegen, nicht in alten JSON-Dateien.
- Standard-Passwort vor oeffentlichem Einsatz ersetzen.
- Rechtstexte vor Launch final pruefen lassen.
- Echte Bilder/Logo koennen spaeter einfach ergaenzt werden.
