SCHRITT 1: Website lokal testen
  $ cd kunsttherapie-site
  $ python3 -m http.server 8080
  → Öffne http://localhost:8080

SCHRITT 2: Inhalte überprüfen
  - Kontaktdaten (Tel, E-Mail, Adresse) ✓ BEREITS DRIN
  - News editieren: data/news.json
  - Texte anpassen: *.html Dateien

SCHRITT 3: Online deployen (EMPFOHLEN: Netlify)
  1. GitHub-Account → kunsttherapie-site repo
  2. Netlify.com → "New site from Git"
  3. Repository wählen → Deploy! 🚀
  → Website live in 1 Minute!

📧 KONTAKTFORMULAR (OPTIONAL)
================================================================================

Option 1: Formspree (einfach)
  1. Gehe zu https://formspree.io
  2. Registriere dich
  3. Erstelle neues Formular
  4. Kopiere action="https://formspree.io/f/xxxxx"
  5. In kontakt.html ersetzen
  → Fertig! E-Mails kommen zu dir

Option 2: Mailto-Link (sehr einfach)
  <a href="mailto:info@kunsttherapie-pb.de">E-Mail schreiben</a>
  → Einfach, aber weniger elegant

Option 3: EmailJS (client-seitig, JavaScript)
