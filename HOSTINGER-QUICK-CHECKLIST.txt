DEPLOYMENT IN 6 SCHRITTEN:

1️⃣  VORBEREITUNG
    ☐ Hostinger hPanel öffnen
    ☐ SSH aktivieren
    ☐ FTP-Daten notieren
    ☐ Node.js verfügbar? (Support fragen)

2️⃣  WEBSITE HOCHLADEN (15 Min)
    ☐ FileZilla öffnen
    ☐ Mit FTP verbinden
    ☐ Ordner erstellen: /public_html/kunsttherapie/
    ☐ Alle Dateien von kunsttherapie-site/ hochladen
    ☐ Testen: https://mkmpb.de/kunsttherapie

3️⃣  BACKEND UPLOADEN (5 Min)
    ☐ SSH öffnen
    ☐ mkdir -p kunsttherapie-cms
    ☐ FTP: server.js, package.json, .env hochladen
    ☐ SSH: npm install

4️⃣  KONFIGURATION (5 Min)
    ☐ .env anpassen:
      PORT=3000
      CORS_ORIGIN=https://mkmpb.de
    ☐ API URL in neuigkeiten.html ändern:
      const API_URL = 'https://mkmpb.de:3000/api';
    ☐ Neuigkeiten.html hochladen

5️⃣  BACKEND STARTEN (5 Min)
    ☐ SSH: npm install -g pm2
    ☐ SSH: pm2 start server.js --name "kunsttherapie-cms"
    ☐ SSH: pm2 startup
    ☐ SSH: pm2 save

6️⃣  TESTS (5 Min)
    ☐ Website testen: https://mkmpb.de/kunsttherapie
    ☐ Admin-Panel: https://mkmpb.de:3000/admin
    ☐ Login: admin/admin123
    ☐ News hinzufügen & überprüfen

GESAMT: ~30-40 Minuten! ⏱️

HÄUFIGE FEHLER & LÖSUNGEN

❌ "npm: command not found"
✅ Node.js nicht installiert/aktiviert
   → Hostinger Support kontaktieren

❌ "Connection refused Port 3000"
✅ Backend läuft nicht
   → SSH: pm2 status
   → SSH: pm2 logs kunsttherapie-cms

❌ Website lädt nicht
✅ Dateien nicht hochgeladen
   → FTP: Dateien im /public_html/kunsttherapie/ Ordner?
   → Browser: Cache leeren (Ctrl+Shift+Del)

❌ News zeigen sich nicht
✅ API_URL falsch oder Backend läuft nicht
   → neuigkeiten.html: API_URL überprüfen
   → Backend: npm run dev testen
   → API testen: curl http://localhost:3000/api/news

❌ "403 Forbidden"
✅ Dateirechte falsch
   → SSH: chmod 755 ./public/
   → SSH: chmod 600 .env

PROBLEMBEHEBUNG

Problem: "npm install" dauert sehr lange
→ Normal, erste Installation dauert 1-2 Min

Problem: Terminal friert ein
→ SSH Verbindung: Neue Session öffnen

Problem: Dateien hochladen ist langsam
→ Nutze SFTP (sicherer & schneller)
→ Lade assets/ im Batch hoch

Problem: Backend startet, reagiert aber nicht
→ SSH: curl http://localhost:3000
→ Sollte HTML zurückgeben
